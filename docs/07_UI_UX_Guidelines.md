# CodeSense AI

## UI / UX Guidelines

**Version:** 1.0\
**Status:** Engineering Baseline

------------------------------------------------------------------------

# 1. Design Philosophy

CodeSense AI should feel like a modern developer tool rather than a
traditional web application.

Core principles:

-   Clarity over decoration
-   Fast workflows
-   Minimal clicks
-   Accessibility first
-   Consistent interactions

------------------------------------------------------------------------

# 2. Visual Identity

-   Theme: Dark-first
-   Accent: Electric Blue
-   Success: Green
-   Warning: Amber
-   Error: Red

Typography:

-   Headings: Inter
-   Code: JetBrains Mono

------------------------------------------------------------------------

# 3. Navigation

Primary sections:

-   Dashboard
-   Debug
-   Optimize
-   Review
-   Learn
-   Reports
-   Settings

Global search should always be available.

------------------------------------------------------------------------

# 4. Dashboard

Widgets:

-   Recent Analyses
-   AI Usage
-   Project Health
-   Learning Progress
-   Quick Actions

------------------------------------------------------------------------

# 5. Debug Experience

Workflow:

1.  Upload code / ZIP / screenshot / GitHub URL
2.  Processing indicator
3.  AI summary
4.  Root cause
5.  Suggested fix
6.  Prevention tips
7.  Export report

------------------------------------------------------------------------

# 6. Component Standards

Buttons: - Primary - Secondary - Destructive

Cards: - Rounded corners - Clear headings - Consistent spacing

Tables: - Sortable - Searchable - Responsive

------------------------------------------------------------------------

# 7. Accessibility

-   WCAG AA contrast
-   Keyboard navigation
-   Focus indicators
-   Screen reader labels

------------------------------------------------------------------------

# 8. Responsive Design

Support:

-   Desktop (primary)
-   Tablet
-   Mobile (basic)

------------------------------------------------------------------------

# 9. Empty States

Every empty page should guide the user with:

-   Explanation
-   Action button
-   Helpful examples

------------------------------------------------------------------------

# 10. Loading & Errors

Loading: - Skeleton screens - Progress indicators

Errors: - Friendly language - Recovery actions - Retry button
